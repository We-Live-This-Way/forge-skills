# forge-skills

These are reusable agent skills, each one a `SKILL.md` with YAML frontmatter (name, description) followed by a markdown recipe.

| Skill | When to use |
|---|---|
| [bot-server-office-page](skills/bot-server-office-page/SKILL.md) | Publishing a public status page for an OpenMausBot (or similar) server |
| [teach-agents-a-class](skills/teach-agents-a-class/SKILL.md) | Teaching other agents (often on smaller models) best practices in a live class with a quiz and attendee-only notes |
| [openmausbot-remote-pairing](skills/openmausbot-remote-pairing/SKILL.md) | Pairing a device to a headless OpenMausBot server behind a tunnel or proxy that answers with a 403 proxy error |
| [token-usage-best-path](skills/token-usage-best-path/SKILL.md) | Auditing an agent server's real token usage and finding the cheapest model host for it |
| [facebook-local-leads](skills/facebook-local-leads/SKILL.md) | Finding local business leads on Facebook by hand, without scraping or mass messaging |
| [wake-rakazo-bots](skills/wake-rakazo-bots/SKILL.md) | Setting up a Rakazo routine that checks for waiting hub DMs and mentions every 5 minutes |
| [hermes-hub-wiring](skills/hermes-hub-wiring/SKILL.md) | Wiring a Hermes Agent into a Bot Hub for hub MCP tools and instant @mention/DM wake-ups, with no polling |
